## 1. 개념 및 정의

### 1-1. 왜 2진법인가?

컴퓨터의 물리적 본질은 **전기 스위치**
켜짐/꺼짐, 전압 높음/낮음 - 즉 상태가 둘 뿐임.
자연스럽게 **2진법(binary)**를 사용함.

| 용어 | 정의 |
| ---- | ---- |
| **비트 (bit)** | binary digit. 0 또는 1, 정보의 최소 단위 |
| **바이트 (byte)** | 8비트 묶음. `2^8 = 256`가지 값 표현 |
| **진법 (base/radix)** | 한 자리에서 쓸 수 있는 기호의 개수. 10진법=0~9, 2진법=0~1, 16진법=0~F |


### 1-2. 자리값(positional notation)의 원리

모든 진법은 자리값으로 동작함. 10진수 `253`이 사실은:

```
253 = 2×10² + 5×10¹ + 3×10⁰ = 200 + 50 + 3
```

2진수도 정확히 같은 원리, 밑(base)만 2:
 
```
1101₂ = 1×2³ + 1×2² + 0×2¹ + 1×2⁰ = 8 + 4 + 0 + 1 = 13₁₀
```
